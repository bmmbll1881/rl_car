# 超车鲁棒性优化交接

交接模型位于 `runs/robust_stage12_exact_recovery_bc_s2init/`。一起保留该目录中的 `ckpt_final.npz` 和 `config.json`，以及两份 `runs/robust_stage12_eval_stage*_env.json`。运行时通过场景文件显式覆盖训练目录的环境配置。

最终模型从旧 Stage 2 权重初始化，用无状态专家在候选策略实际访问的状态上补标纠正动作，再做行为克隆。单纯混合两阶段的专家完整轨迹时，独立测试仍出现超车后出界。初轮开发试验也使用了与原归档不一致的环境参数，最终验收使用完整归档配置。

| 原归档场景 | 种子 | 指标 | 旧权重 | 新权重 |
| --- | --- | --- | --- | --- |
| Stage 1 | 67000–67009 | 严格安全超车 / 完整圈 / 出界 | 8 / 10 / 0 | 10 / 10 / 0 |
| Stage 2 | 67100–67109 | 严格安全超车 / 完整圈 / 出界 | 0 / 2 / 8 | 10 / 10 / 0 |

各组 10 回合，实际碰撞均为 0。验收脚本的终端碰撞汇总也计入出界，碰撞以逐回合 JSON 或 `eval_collision_rate` 为准。本次验证覆盖 MiniDrive 的这两套归档场景。147 项单元测试通过。

在 `rl_autodrive` 目录执行以下命令复跑。

```powershell
python scripts/accept_overtake.py --run runs/robust_stage12_exact_recovery_bc_s2init --ckpt ckpt_final.npz --env-json runs/robust_stage12_eval_stage1_env.json --seed-base 67000
python scripts/accept_overtake.py --run runs/robust_stage12_exact_recovery_bc_s2init --ckpt ckpt_final.npz --env-json runs/robust_stage12_eval_stage2_env.json --seed-base 67100
```

逐回合记录位于 `runs/robust_stage12_recovery_heldout_stage1.json` 和 `runs/robust_stage12_recovery_heldout_stage2.json`，旧模型对照位于 `runs/robust_stage12_baseline_heldout_stage1.json` 和 `runs/robust_stage12_baseline_heldout_stage2.json`。
